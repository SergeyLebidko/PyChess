# Атрибуция спрайтов

Файлы `*.png` в этом каталоге получены из набора шахматных фигур **Cburnett**
(автор — Colin M.L. Burnett), опубликованного на Wikimedia Commons.

- Источник: https://commons.wikimedia.org/wiki/Category:SVG_chess_pieces
- Отдельные файлы, например:
  - https://commons.wikimedia.org/wiki/File:Chess_qlt45.svg (белый ферзь)
  - https://commons.wikimedia.org/wiki/File:Chess_kdt45.svg (чёрный король)
- Лицензия: **CC BY-SA 3.0** (https://creativecommons.org/licenses/by-sa/3.0/)
  либо GFDL.

Спрайты сгенерированы скриптом `tools/build_sprites.py` из соответствующих
SVG-файлов. При распространлении проекта необходимо сохранять указание
авторства и лицензии, а производные работы распространять под совместимой
лицензией.
